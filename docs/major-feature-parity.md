# 主要功能复现与后台核验

更新：2026-10-13。对照 ZenlessZoneZero-OneDragon main `6ba72c8`（2026-10-12，已同步到本仓库）。
「后台」指首页选「后台模式」：虚拟手柄输入，不抢前台、不移动鼠标。

## 核验标准

- 存在应用类或配置控件，不等于功能已复现。
- 离线回归通过，不等于实机全流程成功。
- 后台窗口消息被忽略，不等于手柄无法实现；需要检查实际按键提示和焦点。
- 账号未解锁、入口未识别、权限拦截、代码未适配分别记录，不混为“不支持”。
- 不为验证导航而销毁驱动盘。战斗与其它消耗按用户授权范围执行。

## 本轮修复要点

- 同步上游 20 个提交：洛克茜、克拉蕾官方模板，迷失之地六级优先级与入口层重复交互修复，兑换码样例，结束后休眠/睡眠等。
- 首页前后台开关成为唯一输入设置后，旧配置中的 Pynput 会让所有任务转到前台；启动时按方案版本迁移一次到后台模式。
- 后台等待保护：同一状态、画面 180 秒不变即判定后台输入未生效，不再无限等待。
- 实时调试可按应用 ID 单独运行任意应用（如 scratch_card）。

优先继续：枯萎之都手柄流程、式舆防卫战、对话类手柄输入、锄大地传送；驱动盘拆解需要用户放开权限后再演练。
