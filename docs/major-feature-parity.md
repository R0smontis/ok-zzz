# 主要功能复现与后台核验

更新：2026-10-17。对照 ZenlessZoneZero-OneDragon main `6ba72c8`（2026-10-12，已同步到本仓库）。
「后台」指首页选「后台模式」：虚拟手柄输入，不抢前台、不移动鼠标。

## 核验标准

- 存在应用类或配置控件，不等于功能已复现。
- 离线回归通过，不等于实机全流程成功。
- 后台窗口消息被忽略，不等于手柄无法实现；需要检查实际按键提示和焦点。
- 账号未解锁、入口未识别、权限拦截、代码未适配分别记录，不混为“不支持”。
- 不为验证导航而销毁驱动盘。战斗与其它消耗按用户授权范围执行。

实机暴露并修复的问题（均有真实画面夹具和回归）：

- 暂离的副本在「下一步」后弹出「当前正在处理…是否继续？」。核验确认焦点后按一次A，弹窗关闭才算继续成功。
- 续跑后棋盘有拉近动画。现在要求「当前」位置在两帧之间不变才推摇杆。
- 上游的广度搜索会让排队节点被更长的同代价路线覆盖；鼠标点终点由游戏寻路，所以没暴露。手柄逐格走时会在两个空白格之间往返，或在两扇门之间交替。现在从当前格重新计算到目标的最低代价路线（避开格数、步数、经过格数），只取第一步；连续12次只走空白格会停止。
- 商人、守门人、门扉格要在进入后才出现右侧选项（例如「A 进入「守门人」战斗」）。核验移动后运行上游的入口处理；关闭的门不让「当前」移动，而是直接弹出选项，此时同样交给入口处理，不再重复推摇杆。
- 换成手柄后多个处理仍在用窗口消息点击，并误报成功。已改为核验焦点、只按一次、等画面真正变化：及时补给、确认鸣徽／获得战利品、获得弹窗、受到侵蚀弹窗、各种鸣徽卡（选择／丢弃／交换／催化）、非鸣徽卡（临时拍档的助战邦布）、呼叫增援选项、旧都失物（B）、战斗结算「A 确定」、通关结算「B 完成」、菜单放弃（START → Y → 确认）。
- 灰色不可选的事件选项被手柄跳过，原逻辑会一直尝试移过去。现在把灰色选项排除在候选外（与上游白色遮罩OCR的效果一致）。
- 手柄界面里「完成」位于B键图标右侧，超出原「战斗结果-完成」「通关-完成」的识别区域；两个区域已向右放宽。
- 新连接的手柄偶尔几秒内不响应摇杆。未移动的重试改为间隔更长、最多4次，仍不计入移动。

仍未覆盖：邦布商店在后台暂不进入（不购买，继续寻路）；「呼叫增援」本局几次都直接进入及时补给，选人分支没有实机画面；满背包、旧都失物、战斗失败撤退只有代码路径，没有实机验证。完整回归 1223 项通过，打包检查 ok。
