# 克拉蕾与洛克茜专属战斗模板

更新日期：2026-10-07。用户所说“洛克希”按游戏内名称“洛克茜（Roxy）”实现。

## 使用方法

自动战斗的“战斗配置”选择 **全配队通用** 即会按识别到的角色加载各自模板；也可选择新增的 **专属配队-克拉蕾-洛克茜**。两人无需固定槽位，第三人沿用原有角色策略；切换方向由实际队伍识别决定。已有用户自定义同名 `.yml` 保持优先，不覆盖。模板同时用于副本应用采用的战斗配置。

新增洛克茜的角色枚举、战斗前台/后台头像、连携、快速支援、空洞和预设编队资源。没有识别到普攻按钮时，新增角色及轮换分支不发送战斗操作；整体是否开始战斗仍由已有敌人检测和任务状态控制。

## 克拉蕾

根据实际“猩红铭刻”红条选择分支：没有铭刻且特殊技可用时点按特殊技；进入铭刻后采用两次普攻、第三段长按、长按特殊技的循环，积累并消耗残痕。检测到红条归零立即清除状态，不再依赖猜测的铭刻剩余时间。识别失败 `-1` 不当作归零。

普攻第三段、长特殊技目前各按住约 1 秒，点按特殊技后等待 0.9 秒；这些是初始动作参数，需要按当前游戏版本与实际录制调整。没有敌人残痕层数的可靠识别，所以不会把三层残痕写成已确认状态，也不会保证每轮三个毁伤。终结技只有开关开启并且按钮状态新鲜时进入，使用尝试冷却防止连续发送。

## 洛克茜

能量状态在 0.5 秒内、能量至少 90 且特殊技可用时长按特殊技约 2.9 秒，再松开并给风炮/后续动作 1.5 秒初始等待。自动衔接的技能由游戏执行；脚本不额外乱按特殊技，也不伪造风能、风眼和队伍增益已经生效的状态。

充能动作正常结束，或能量不足时，识别到后台克拉蕾便交出前台；其他队伍继续采用通用轮换规则。非洛克茜前台时，只在后台确实识别到她、能量足够并且不处于失衡输出窗口时切入。充能尝试冷却为 5 秒，切入尝试为 3 秒，防止截图延迟导致反复切入。

目前没有可靠风能/风眼视觉识别。90 能量、2.9 秒来自上游录制说明，是保守初始值，不等同于本机实战确认。遭到实时闪避或支援事件打断时会松键；此时不会写“出场结束”。再进入充能需满足冷却与最新能量条件。

## 支援、闪避和终结技

两人都有支援/闪避反击/连携后续。旧红光分支请求闪避时先闪后普攻；如果近 0.5 秒已发过闪避，不重复发送。实时警报仍可打断长按；新循环不会持续设置无视闪光或动作不打断。

关闭自动终结技会跳过两人的完整终结技分支，包括等待和尝试冷却，不只是在控制器处拦截按键。
