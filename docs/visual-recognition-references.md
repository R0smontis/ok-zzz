## 离线验证结果与限制

核对洛克茜官方第一张动图的六个时刻，风能 HUD 都是相同的一格红色加两格暗灰；只有动作区域变化。这是静态 UI 示意，不能拿六帧冒充六种风能状态。

对已有真实录屏 `tests/fixtures/combat_recording/unknown_front_team.png` 做探索性多尺度匹配，该图实际编队为丽娜、克拉蕾、洛克茜。直接用网络单格模板匹配，空格最高相关系数约 0.6801，但位置落在背景而非正确风能图标；红格最高约 0.4450，也不能可靠接受。结果和标注图在 `recorded-wind-probe.json`、`recorded-wind-probe.png`。

这些数值是单张图的探索结果，不是可上线阈值。图像缩放、压缩、示意图发光边缘和前后台不同尺寸会改变匹配结果。当前没有因此启用新自动切人或提前松 E；现有能量判断与有限时长动作继续使用。

可靠识别需要结合已确认的角色槽位、固定局部区域、排除背景的掩膜、空格与亮格的联合判断，以及连续帧确认。完整验证还需要当前版本的 0/1/2/3 点风能及残痕层数样本，包含前后台、不同分辨率、被特效遮挡和空场景等情况。风眼更适合从连续画面验证生成/消失事件，不能仅凭静态外观推断数量或增益已经生效。
