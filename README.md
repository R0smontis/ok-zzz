# ok-zzz

《绝区零》PC 版日常自动化助手。基于 [ok-script](https://github.com/ok-oldking/ok-script) 框架，游戏逻辑移植自 [ZenlessZoneZero-OneDragon（绝区零一条龙）](https://github.com/OneDragon-Anything/ZenlessZoneZero-OneDragon)。

主打 **后台模式**：用虚拟手柄操作游戏，不抢前台、不动鼠标，游戏窗口被遮挡时也能运行（不能最小化）。

> ⚠️ 本项目仅供学习交流。使用第三方工具可能违反游戏用户协议并导致封号，风险由使用者自行承担。

## 下载与安装

1. 在 [Releases](https://github.com/R0smontis/ok-zzz/releases) 下载最新版本的安装包并运行：
   - `ok-zzz-win32-Global-setup.exe`：完整安装包，已包含运行环境，推荐。
   - `ok-zzz-win32-online-setup.exe`：在线安装包，体积小，首次启动时下载运行环境。
2. 使用后台模式需安装虚拟手柄驱动 [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases)（下载 `ViGEmBus_*_x64_x86_arm64.exe` 安装一次即可）。只用前台模式可以不装。
3. 启动 ok-zzz。若游戏以管理员身份运行，ok-zzz 也需以管理员身份运行。

环境要求：Windows 10/11 64 位；游戏 16:9 窗口或全屏，分辨率不低于 1280×720（1080P、1440P、4K 均可）。

## 更新

与 [ok-ww](https://github.com/ok-oldking/ok-wuthering-waves) 相同，安装后由启动器在线更新，无需重新下载安装包：

- 启动时自动检查新版本；也可在「关于」页手动检查、切换版本，或选择自动更新方式（手动 / 自动仅正式版 / 自动含测试版）。
- 更新只替换程序文件，账号配置、日志等用户数据保留在安装目录中。
- 启动器自身的修复需更换启动器或安装新版安装包；应用在线更新只更新Python工作目录。更新检查网络失败时会显示原因；已有完整安装且开启自动启动时仍可启动本地版本。

从 0.1.x 独立安装版升级：请安装新版安装包；如需保留设置，把旧版运行目录 `%LOCALAPPDATA%\ok-zzz` 下的 `configs` 和 `config\01` 文件夹复制到新安装目录后再启动。

## 使用方法

1. **选择游戏窗口**：在「截图方式」页选择《绝区零》窗口，并选择输入方式：
   - **后台模式**（推荐）：虚拟手柄 + 窗口消息，可以边用电脑边挂机。游戏只响应最近使用的输入设备，挂机时请不要同时用键鼠操作游戏。
   - **前台模式**：键鼠操作，运行时把游戏切到前台，切走时暂停。
2. **一条龙日常**：在侧边栏「一条龙日常」勾选要执行的项目，拖动调整顺序，点「编辑」修改各项设置（如体力刷本的刷本计划），然后开始。游戏停在登录画面时会先自动登录。
3. **单独运行**：侧边栏的每个应用都可以单独运行，例如迷失之地、锄大地、枯萎之都。
4. **常驻助手**：勾选「自动战斗」「闪避助手」「自动跳过对话」后，进入对应画面时自动接管。

体力刷本默认 **每次执行都完整走一遍刷本计划**；如需刷到电量用完，在体力刷本设置中开启「循环执行」。

专业挑战室计划可设置「无双倍时」：默认「停止」；「等体力单倍」将每个剩余双倍次数替换为2场单倍；「等次数单倍」替换为1场单倍。仅在入口明确核验无双倍可用时生效，不会因识别失败自动回退。

## 常见问题

- **后台模式没有反应**：确认已安装 ViGEmBus 并重启 ok-zzz；游戏窗口不能最小化。
- **识别不准或点错位置**：游戏需为 16:9 分辨率，关闭 HDR 与画面滤镜。
- **检查更新提示「未找到启动器」**：安装目录中的 `ok-zzz.exe` 可能被杀毒软件隔离（常见为 `Trojan:Win32/Bearfoos.A!ml` 误报）。在 Windows 安全中心恢复该文件，并把安装目录加入排除项；无法恢复时重新安装。
- **反馈问题**：在 [Issues](https://github.com/R0smontis/ok-zzz/issues) 描述现象。「调试 → 画面与日志诊断」可以录制截图、视频和日志（自动遮挡 UID），附上诊断包更便于排查。

## 从源码运行

需要 Python 3.12：

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install --no-deps -r requirements.lock.txt
python main.py           # 正常运行
python -m pytest -q      # 离线测试（无需游戏）
```
